# Pikura 2.0.0 — Major Release 🎉

This is the biggest update to Pikura yet, introducing three brand-new tabs, a full onboarding experience, and significant performance work across the app.

## ✨ New Features

### 🌐 Pixivision Tab
Browse official Pixivision articles, artist interviews and featured spotlights without leaving the app. Save articles for later and filter content to your taste.

### 🔍 Search Tab
A new global Search tab lets you look up artworks, artists, novels and users with a single query across the app.

### 🕘 Viewed Tab
Every artwork you open is remembered in the new Viewed tab. Scroll back through your viewing history to rediscover images, or use the built-in calendar to jump to what you viewed on any past day.

### 🖼️ Artwork Background Overlay
Use any artwork as a full-window background overlay. Tune opacity, brighten/darken, pan and zoom per image, or cycle through up to five favorites.

### 🔎 Gallery Search
Search within the gallery by tag, title, artist, caption, date range, R-18 mode, AI generation and more. Combine filters and sorting to narrow down your collection quickly.

### 🎛️ Advanced Filtering
Filter by AI generation, R-18 type, blocklist scope, tags, titles and artists — independently in Gallery, Rankings, Discover, Search and Pixivision.

## 🚀 Performance Improvements
- Reduced memory usage and faster startup
- Smoother gallery scrolling
- More responsive download coordination
- Thread-safe animated image decoding with instant-display frame preloading

## 🧰 Other Changes
- What's New onboarding splash showcasing new features on major updates
- GitHub Page link on the About settings page
- Numerous bug fixes and UI polish throughout the app

## 📦 Installation
- **Windows (recommended):** download and run `Pikura-2.0.0-Setup.exe`
- **Portable:** download and extract `Pikura-2.0.0-win-x64.zip`

Existing users will be offered this update automatically via the in-app updater.
